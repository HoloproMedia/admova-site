Géofencing, géociblage, géolocalisation : quelles différences ?

Ces quatre mots reviennent dans toutes les offres de publicité locale. Ils ne désignent pas la même chose, et la différence compte pour le budget.

Publié le 23 septembre 2026 · Admova

La géolocalisation : savoir où se trouve un appareil

La géolocalisation est la donnée de base : la position d’un smartphone, obtenue par GPS, par le réseau mobile ou par le Wi-Fi. Le GPS est le plus précis, de l’ordre de quelques mètres. La position déduite de l’adresse IP, elle, peut se tromper de plusieurs kilomètres.

Seule, la géolocalisation ne fait rien : c’est une information, pas une campagne.

Le géociblage : diffuser selon cette position

Le géociblage consiste à n’afficher une publicité qu’aux personnes présentes dans une zone donnée. La qualité du géociblage dépend entièrement de la source de la position : un ciblage par ville ou par code postal reste approximatif, un ciblage par GPS peut descendre à l’échelle d’une rue.

Le géofencing : tracer une frontière virtuelle

Le géofencing, en français géo-repérage, trace un périmètre précis autour d’un lieu : un cercle autour d’un magasin, ou le contour d’un centre commercial. On parle aussi de geofence pour désigner ce périmètre. Dès qu’un appareil se trouve à l’intérieur, il devient éligible à la diffusion.
